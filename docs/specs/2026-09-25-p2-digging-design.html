P2 지하 굴착·확장 설계서

  • 상태: 승인 (2026-09-25)

  • 작성: 2026-09-25

  • 상위 문서: 게임 기획서 — 이 설계서의 결정 번호(D…)는 기획서 2장 "결정 기록"을 따른다.

  • 이 단계의 결정: D41~D52 (전제: D8·D9·D24·D25·D27·D28·D31·D33·D34·D35·D40)

1. 목적과 범위

플레이어의 유닛이 블록을 캐며 지하 공간을 넓히는 시스템을 정의한다. 핵심 루프의 첫 고리이자 첫 회색 박스 프로토타입의 대상이다.

포함포함하지 않음 (담당 단계)
블록 종류와 등급, 굴착 속도 규칙광맥에서 나오는 자원의 양·종류, 캔 암반이 재료가 되는지 (P3)
시야(스캐너) 규칙굴착병의 체력·가격·생산 (P4)
굴착 방침과 굴착 작업 배정포탈에서 나오는 적, 적 AI (P5)
공간 규칙: 파낸 곳에만 건설, 벽 설치건물 종류와 기능 (P3·P4)
지역 격자, 굴착 가능 영역, 전진 기지지역 관리자 도구의 화면 (P6)
시드 기반 지형 생성배치 기억·프리셋의 저장 방식 (P8)

2. 규칙

2.1 블록 종류 (D52)

종류등급캘 수 있나캐면
일반 암반1~6예 (2.2 규칙)같은 등급의 석재가 된다 (D55, P3)
광맥1~6예자원이 나오고 점점 고갈(D15). 양은 P3
유물 매장지지역별예유물 획득(P8)
포탈 봉인지역별예포탈이 열림(P5)
적 기지 외벽적 종족별예적 기지와 맞닿음(P5)
환경 블록지역별예불안정 암반: 옆을 파면 무너짐 / 용암: 흘러나와 주변 피해 / 독가스 주머니: 터지면 구역 피해. 종류와 비율은 지역 데이터(D34)
경계 암반—아니요— (굴착 가능 영역 밖, 진출하지 않은 지역과의 경계)
설치 벽석재 등급 (D55)예 (적도 같은 규칙)사라짐 (D47)

2.2 등급과 굴착 속도 (D41·D42)

  • 굴착 능력은 유닛이 병참 건물에서 만들어질 때 쓴 도구 등급이다. (D42)

  • 굴착 속도 = 유닛의 기본 굴착 속도 × 등급 차 배율

    블록 등급 − 유닛 등급배율
    0 이하1.0
    +10.2 [가정]
    +2 이상0 (불가)

  • 적도 같은 규칙으로 암반과 설치 벽을 판다(D46). 그래서 "한 등급 높은 벽"은 적을 오래 붙잡아 두는 방어 수단이다.

2.3 시야 (D43)

상태보이는 것
처음부터암반 등급, 큰 광맥
파낸 공간에서 일정 거리 안 [가정: 3칸] 또는 스캐너 범위 안포탈 봉인, 적 기지 외벽, 유물 매장지, 작은 광맥, 환경 블록

  • 스캐너 단계가 오르면 범위가 넓어지거나 더 많은 종류가 보인다. [가정] 스캐너는 판 안 업그레이드, 영구 강화로 시작 단계를 높일 수 있다.

2.4 굴착 방침과 작업 배정 (D45·D48)

방침 다섯 가지를 우선순위 목록으로 켜고 순서를 정한다.

방침후보 블록
목표 지점 뚫기플레이어가 찍은 지점까지의 최단 굴착 경로 위 블록
특정 자원 우선체크한 자원(여러 개)의 보이는 광맥
자원 우선보이는 모든 광맥
확장 우선굴착 가능 영역 안에서 아직 안 판 블록, 본부·전진 기지에서 가까운 순
안전 우선확장 후보 중 보이는 위험(포탈 봉인·적 기지 외벽·환경 블록)과 일정 거리 이상 떨어지고, 본부 주변 벽 두께 [가정: 2칸]를 남기는 블록

작업 배정 흐름 — 할 일이 없는 굴착병마다:

  1. 목록의 1순위 방침부터 후보 블록을 찾는다.

  2. 후보 중 굴착 가능(배율 > 0)하고, 파낸 공간과 맞닿아 있으며, 다른 굴착병이 예약하지 않은 블록을 고른다. 여러 개면 가까운 것부터.

  3. 후보가 없으면 다음 순위 방침으로 내려간다.

  4. 고른 블록을 예약하고 이동해 판다. 다 파면 블록이 사라지고 "블록 제거" 이벤트가 나간다(2.7).

  5. 플레이어가 구역을 직접 지정하면 그 구역은 모든 방침보다 앞선다(D24).

2.5 공간 규칙 (D46·D47)

  • 건물과 설치 벽은 파낸 빈 칸에만 놓을 수 있다.

  • 설치 벽은 파낸 칸을 다시 막는다. 건물처럼 배치 기억·자동 설치·프리셋 대상이다(D25·D47).

  • 남겨둔 암반과 설치 벽이 적의 진로를 결정한다. 기지 설계 = 어디를 파고 어디를 남기고 어디를 막을지.

2.6 지역과 굴착 가능 영역 (D49·D50·D51)

  • 지역은 격자형이다. 시작 지역이 가운데이고, 8방향으로 맞닿은 지역에 진출한다. 시작 지역에서 멀수록 어렵다.

  • 진출할 수 있는 지역 수는 탐사 단계로 제한되고, 플레이어가 고른 지역에만 들어간다(D33).

  • 굴착 가능 영역은 중심에서의 반경으로 정해진다.

    • 시작 지역의 중심은 본부다. (D50)

    • 다른 지역의 중심은 진출할 때 세우는 전진 기지다. (D51)

    • 반경은 판 안 레벨로 커진다(모든 중심에 같은 반경 [가정]).

  • [가정] 전진 기지가 무너져도 판은 끝나지 않는다. 그 지역의 굴착 가능 영역이 어떻게 되는지는 열린 점(8장).

2.7 블록 제거 이벤트가 다른 시스템에 주는 것

받는 쪽내용
시야주변 칸 공개 갱신
P3 경제광맥이면 자원 생성
P5 조우포탈 봉인이면 포탈 열림, 적 기지 외벽이면 조우 시작
P8 성장굴착 경험치(D30), 유물 매장지면 유물
화면해당 청크 다시 그리기

3. 지형 생성 (D28·D52)

  • 입력: 판 시드, 지역 좌표 (x, y), 그 지역의 지역 데이터(RegionDef)

  • 지역마다 따로 난수 생성기를 만든다: 지역 시드 = Hash(판 시드, x, y). 한 지역의 생성 규칙을 고쳐도 다른 지역의 지형은 바뀌지 않는다.

  • Unity의 전역 Random 대신 자체 난수 생성기(예: PCG, xorshift)를 쓴다. 다른 코드가 난수를 먼저 뽑아 결과가 달라지는 일을 막기 위함이다.

  • 생성 순서(고정):

    1. 암반 등급장: 시작 지역 중심에서의 거리로 기본 등급을 정하고, 노이즈로 불규칙하게 섞는다.

    2. 광맥: 지역 데이터의 자원표에 따라 무리(클러스터)로 뿌린다. 높은 등급 자원일수록 먼 곳에 둔다.

    3. 환경 블록: 지역 데이터의 비율대로 배치한다.

    4. 특수 블록: 유물 매장지, 포탈 봉인(거리·행성 위협도에 따른 확률, 세부 P5).

    5. 강제 배치: 원수 진영과 전임자 지점을 저장된 상대 위치에 놓는다(D27). 겹치는 칸은 덮어쓴다.

    6. 경계 암반: 지역 가장자리와 굴착 가능 영역 밖.

4. 구조 (Unity 구현 방향)

4.1 데이터 (ScriptableObject)

Unity의 ScriptableObject는 코드와 분리된 데이터 파일이다. 새 블록·지역을 추가할 때 코드를 고치지 않고 파일만 만든다(데이터 주도 원칙).

데이터주요 내용
BlockDef종류, 등급, 캐면 나오는 것(P3 연결), 환경 효과, 시야에 보이는 조건
RegionDef크기, 암반 등급 범위, 자원표, 환경 블록 비율, 등장 적 종족, 유물표, 격자 좌표
DigPolicyDef방침 종류와 조정값(예: 안전 거리, 벽 두께)

4.2 시뮬레이션 (화면과 분리된 순수 C#)

  • RegionGrid: 128×128 칸 배열. 칸마다 블록 id, 굴착 진행도, 예약 여부를 가진다.

  • DigArea: 중심(본부·전진 기지)과 반경.

  • VisibilityMap: 칸마다 "보임" 상태.

  • DigJobBoard: 우선순위 방침으로 후보를 찾고 굴착병에게 배정한다(2.4).

  • 시뮬레이션은 고정 간격(틱)으로 돈다. 화면 프레임과 분리해야 결과가 컴퓨터 성능과 무관해지고, 중단 저장 후 이어하기(D17)와 나중의 멀티(D8)가 쉬워진다.

4.3 화면

  • 지역을 32×32 청크로 나눠 청크마다 메시 하나로 그린다. 보이는 청크만 그린다(기획서 4.1 최적화 원칙).

  • 시뮬레이션의 "블록 제거" 이벤트를 받아 그 청크만 다시 만든다.

4.4 명령 (D8)

플레이어 입력은 모두 명령 객체로 시뮬레이션에 전달한다. 배치 기억(D25)은 이 명령을 저장해 다음 판에 다시 실행하는 것이다.

명령내용배치 기억 대상
DesignateDig구역 직접 지정아니요
SetDigPolicies방침 우선순위 목록 설정[가정] 예 (방침도 프리셋에)
PlaceWall벽 설치예
PlaceForwardBase전진 기지 설치[가정] 아니요 (지역 진출은 매 판 선택)

6. 다른 단계와의 접점

단계여기서 넘겨주는 것거기서 정할 것

7. 테스트와 검증

무엇을어떻게
지형 결정성같은 시드·같은 지역 좌표로 두 번 생성해 칸 배열이 완전히 같은지 비교. 한 지역의 규칙을 바꿔도 다른 지역 결과가 같은지 확인
굴착 속도 규칙등급 차 −2 ~ +3의 표 테스트
작업 배정작은 격자와 방침 목록을 주고 굴착병이 고르는 블록이 예상과 같은지
예약굴착병 둘이 같은 블록을 고르지 않는지
시야파낸 칸에서 3칸 안의 특수 블록만 공개되는지
성능 [가정 목표]굴착병 100명의 작업 배정이 한 틱에 1ms 안
회색 박스 체감굴착병 10명이 방침대로 파는 모습을 30분 지켜봐도 "왜 저기를 파는지" 이해되는가
